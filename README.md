# Personal Budget & Expense Tracker

## Project Description

This project is a Personal Budget & Expense Tracker created using HTML and CSS. It helps users organize and view their expenses in a simple and clear layout.

For this week's assignment, I improved the visual design of my existing Budget Tracker without adding new HTML functionality.

## What I Built

I improved the Budget Tracker by adding:

- A consistent color palette
- Custom Google Fonts
- Styled headings and text
- A styled Add Expense form
- A styled expense table
- Table borders, spacing, and hover effects
- CSS Box Model properties
- Card-style sections for the page heading, Add Expense form, and Expense Table

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## Main Sections

### Page Heading
The page heading introduces the Budget Tracker and uses custom typography, colors, spacing, borders, and rounded corners.

### Add Expense Form
The form contains fields for entering an expense name, amount, and category. CSS was used to improve the spacing, borders, input fields, and button.

### Expense Table
The expense table displays expense information in an organized format. It includes styled table headers, borders, padding, alternating row colors, and hover effects.

## CSS Design

The project uses a consistent color palette:

- Light background
- Dark teal headings
- Green buttons
- White table header text

The project also uses *Poppins* for headings and *Roboto* for general text.

## Project Files

- index.html - Contains the structure and content of the Budget Tracker.
- style.css - Contains the visual design and styling.
- README.md - Explains the project and the work completed.

## Conclusion

This project demonstrates how CSS can be used to improve the appearance, readability, organization, and user-friendly design of an existing web application.
